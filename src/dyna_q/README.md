# Dyna-Q для Stochastic FrozenLake 8x8

Эта папка содержит реализацию агента Dyna-Q для стохастической среды FrozenLake 8x8.

## Обзор логики

Решение состоит из:

1. **StochasticEnvModel (`model.py`)**: Изучает вероятности переходов $T(s, a, s')$ и ожидаемые награды $R(s, a, s')$.
2. **DynaQAgent (`agent.py`)**:
    * Использует **Q-learning** для прямого обновления на основе реального опыта.
    * Использует **Планирование** (симуляцию) для обновления Q-значений на основе изученной модели ($n$ шагов планирования на один реальный шаг).
3. **Обучение (`train.py`)**: Сравнивает чисто безмодельный Q-learning ($n=0$) с Dyna-Q ($n=5, 50$).

## Установка

Убедитесь, что установлены зависимости проекта:

```bash
uv sync
```

## Запуск обучения

Чтобы обучить агентов и сгенерировать графики сравнения:

```bash
uv run python src/dyna_q/train.py
```

Это выполнит следующие действия:

* Обучит агентов Dyna-Q с $n=0, 5, 50$ шагами планирования.
* Сохранит обученные модели в `results/models/`.
* Создаст график сравнения в `results/dyna_q_comparison.png`.

**Примечание**: Обучение 10 000 эпизодов для каждой конфигурации занимает несколько минут.

## Визуализация

Чтобы посмотреть, как играет обученный агент:

```bash
# По умолчанию (запускает модель n=50)
uv run python -m src.dyna_q.visualize

# Указать модель и скорость
uv run python -m src.dyna_q.visualize --model results/models/dyna_q_n50.pkl --delay 0.05
```

## Результаты

Dyna-Q с $n=50$ шагами планирования значительно превосходит стандартный Q-learning ($n=0$) на сложной стохастической карте 8x8, достигая ~50% "success rate", в то время как Q-learning не может обучиться (0%).
